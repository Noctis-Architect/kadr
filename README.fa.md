# کادر (kadr)

[English](README.md) · **فارسی**

**کادر** یه ویرایشگر ویدیوی سبک و محلیه که هوش مصنوعی می‌تونه باهاش کار کنه. همه‌چیز توی فایل‌های ساده‌ی پروژه ذخیره میشه، پس هم خودت با موس ادیت می‌کنی و هم ایجنت‌هایی مثل Claude Code، Codex یا Gemini، و هر تغییری همون لحظه توی پیش‌نمایش دیده میشه.

اسمش از «کادر» میاد: هم در فارسی (قاب) و هم در روسی (кадр، یعنی فریم فیلم).

- همه‌چیز روی کامپیوتر خودت اجرا میشه؛ هیچ فایلی جایی آپلود نمیشه.
- رایگان و متن‌باز (MIT).
- فقط Node.js، بدون هیچ وابستگی npm.

---

## چه کارهایی می‌کنه؟

### ویرایش با حرف زدن
- **چت داخلی:** بنویس چی می‌خوای («سکوت‌ها رو بگیر»، «زیرنویس بذار»، «یه تایتل متحرک بساز») و ایجنت روی همین پروژه کار می‌کنه. هر قدمش رو می‌بینی و هر نوبت با یه کلیک برمی‌گرده.
- **ایجنت دلخواه:** Claude Code، Codex، Gemini CLI، OpenCode، Qoder، Cursor، Qwen Code، Crush، Goose، Aider، Amp، یا هر برنامه‌ی خط فرمان دیگه.
- **Claude Code با مدل‌های ارزون‌تر:** ابزارهای Claude Code رو نگه می‌داری ولی مدل از Z.ai (GLM)، DeepSeek یا Kimi میاد.
- **ایجنت داخلی با کلید API:** Anthropic، OpenAI، DeepSeek، Z.ai، Kimi، Qwen، Mistral، Grok، OpenRouter، Gemini، Groq، Ollama (محلی و رایگان)، یا هر سرور سازگار با OpenAI.
- **ضمیمه کردن فایل:** عکس، موزیک یا متن رو روی چت بکش یا Paste کن.

### بدون باز کردن برنامه، از ایجنت‌های خودت
توی **تنظیمات AI ← Use from your agents** روی **Connect** بزن (یا توی ترمینال `kadr connect claude`). بعد از اون، توی خود Claude Code، Codex، Gemini CLI، Cursor، OpenCode، Qwen Code یا Claude Desktop بگو:

> یه ویدیوی ۳۰ ثانیه‌ای عمودی برای معرفی کافه‌ام بساز، توی ~/Videos/cafe

ایجنت خودش پروژه می‌سازه، ویرایش می‌کنه، فریم‌ها رو نگاه می‌کنه و خروجی می‌گیره. کادر به‌شکل یه سرور MCP به این برنامه‌ها وصل میشه (`kadr mcp`). قبل از تغییر تنظیمات هر برنامه، ازش نسخه‌ی پشتیبان گرفته میشه، و Disconnect فقط بخش مربوط به کادر رو پاک می‌کنه.

### ساخت ویدیو از روی بریف
**AI ← New video from a brief:** بگو چی می‌خوای (معرفی محصول، ویدیوی متن آهنگ، اسلایدشو، ویدیوی توضیحی، ریلز، یوتیوب). عکس‌ها، موزیک، متن آهنگ یا **آدرس سایتت** رو بده و قالب و حس و حال رو انتخاب کن. ایجنت همه رو می‌خونه، سایت رو بررسی می‌کنه (متن، قیمت، رنگ برند، عکس‌ها)، فقط چیزهای لازم رو می‌پرسه، یه برنامه‌ی کوتاه میگه و ویدیو رو می‌سازه.

### عکس، صدا و فیلم
- **عکس و فیلم آزاد از اینترنت:** Wikimedia Commons و Openverse (بدون کلید)، Pexels و Pixabay (کلید رایگان). مجوز هر فایل توی `media/stock/CREDITS.md` ثبت میشه.
- **ساخت عکس با هوش مصنوعی:** OpenAI یا Gemini.
- **گوینده (متن به صدا):** OpenAI، ElevenLabs، یا **Piper و eSpeak که آفلاین و رایگانن**.
- **زیرنویس از روی صدا** با زمان دقیق هر کلمه (Whisper از OpenAI یا Groq).
- کلیدها فقط یک بار وارد میشن، با دکمه‌ی Test چک میشن، و فقط توی `~/.config/kadr/settings.json` روی همین کامپیوتر ذخیره میشن؛ هیچ‌وقت توی پوشه‌ی پروژه نمیرن.

### ویرایش دستی، مثل بقیه‌ی برنامه‌های ادیت
- منوی کامل بالای صفحه: File · Edit · View · Insert · AI · Window · Help
- تایم‌لاین چندترکه: جابه‌جایی، برش، ripple delete، چسبیدن خودکار، مارکر، نقطه‌ی شروع و پایان
- سرعت (۰٫۱ تا ۱۶ برابر، بدون تغییر زیر و بمی صدا)، رنگ، صدا، محو شدن، کراپ، چرخش، فریم ثابت، پخش برعکس
- کی‌فریم برای موقعیت، اندازه، چرخش، شفافیت و صدا
- **ترنزیشن‌ها با یه کلیک:** Dissolve، Dip to black، Flash، Push در چهار جهت، Color wipe، Iris، Stripes
- **چیدمان دلخواه صفحه (Workspace):** چند چیدمان آماده، جابه‌جا و مخفی کردن پنل‌ها، تغییر اندازه با کشیدن، و ذخیره‌ی چیدمان خودت
- ویرایشگر بصری کامپوزیشن‌ها، که توی یه پنجره روی برنامه باز میشه

### تمپلیت‌های آماده
تایتل، لوور‌ترد، زیرنویس کلمه‌به‌کلمه، **متن آهنگ با شش سبک انیمیشن**، تایپوگرافی متحرک، شمارنده، نمودار میله‌ای، نقل‌قول، معرفی لوگو، شمارش معکوس، فلش و برچسب، دکمه‌ی سابسکرایب، کارت پایانی، رنگ و گرادیان، و ترنزیشن‌ها. **متن فارسی و عربی خودکار راست‌به‌چپ** نوشته میشه.

### خروجی حرفه‌ای
H.264، H.265، ProRes 422 HQ، AV1 و VP9، تا 4K. یکسان‌سازی بلندی صدا برای یوتیوب و اینستاگرام (‎-14 LUFS)، پادکست (‎-16) و تلویزیون (‎-23)، و motion blur برای موشن‌گرافیک. پیش‌نمایش و خروجی **فریم‌به‌فریم یکی هستن**.

## Skillها (دستورالعمل‌های آماده برای ایجنت)
هر پروژه این راهنماها رو داره و ایجنت قبل از هر کار، راهنمای مربوط به همون کار رو می‌خونه:

| skill | برای چی |
|---|---|
| `youtube-video` | ویدیوی بلند یوتیوب: کات، شروع جذاب، فصل‌بندی، صفحه‌ی پایانی |
| `shorts-reels` | ریلز، شورتس و تیک‌تاک: عمودی، تند، با زیرنویس و رعایت بخش‌های امن صفحه |
| `instagram-post` | پست و استوری اینستاگرام |
| `social-formats` | X، لینکدین، تلگرام، آپارات و بقیه، و ساختن نسخه برای چند پلتفرم |
| `captions` | زیرنویس کلمه‌به‌کلمه از روی صدا |
| `lyric-video` | ویدیوی متن آهنگ با زمان‌بندی دقیق و انیمیشن مناسب هر آهنگ |
| `video-from-brief` | ساخت کامل یه ویدیو از روی توضیحات، فایل‌ها و سایت |
| `product-promo` | تبلیغ و معرفی محصول |
| `photo-slideshow` | ویدیو از روی عکس‌ها با موزیک |
| `montage-highlights` | مونتاژ سفر، مراسم و ولاگ، هماهنگ با ریتم موزیک |
| `repurpose-clips` | ساختن چند ویدیوی کوتاه از یه ویدیوی بلند |
| `podcast-video` | پادکست و مصاحبه |
| `screencast-tutorial` | آموزش از روی فیلم صفحه |
| `voiceover-explainer` | ویدیو از روی متن، با گوینده و تصویر |
| `thumbnail` | تامبنیل و کاور |
| `color-look` | اصلاح رنگ و یکدست کردن ظاهر کلیپ‌ها |
| `audio-mix` | تنظیم صدا و پایین آوردن خودکار موزیک زیر صدای گوینده |
| `find-media` | پیدا کردن عکس و فیلم آزاد و خوندن سایت |

## پیش‌نیازها
- Node.js نسخه‌ی ۲۲ یا بالاتر
- ffmpeg و ffprobe
- Chromium یا Chrome (برای مسیر دیگه: `KADR_CHROME=/path`)

## شروع کار

</div>

```bash
kadr init ~/videos/launch --demo    # --demo یه فیلم و تایتل نمونه هم می‌ذاره
cd ~/videos/launch
kadr serve --open                   # http://127.0.0.1:4310
```

<div dir="rtl">

بعد یکی از این‌ها:
- توی صفحه‌ی شروع روی **Describe it** بزن و بریف بده،
- یا تب **Chat** رو باز کن و بنویس چی می‌خوای،
- یا یه ایجنت رو توی همون پوشه توی ترمینال اجرا کن (`claude`، `codex`، `gemini`…). ایجنت فایل `AGENTS.md` رو می‌خونه و وقتی می‌گی «این کلیپ» یا «همین‌جا»، می‌دونه کدوم کلیپ انتخاب شده و پلی‌هد کجاست.

## دستورهای مهم خط فرمان

</div>

| دستور | کار |
|---|---|
| `kadr init <پوشه>` | ساخت پروژه‌ی جدید |
| `kadr serve --open` | باز کردن ویرایشگر |
| `kadr connect [برنامه]` | وصل کردن کادر به Claude Code، Codex، Gemini، Cursor و… |
| `kadr mcp` | سرور MCP (برنامه‌ها خودشون اجراش می‌کنن) |
| `kadr frame 3.5` / `kadr sheet` | دیدن فریم یا خلاصه‌ی تصویری کل تایم‌لاین |
| `kadr validate` / `kadr lint` | چک کردن پروژه و کامپوزیشن‌ها |
| `kadr gen image "…"` | ساخت عکس |
| `kadr gen speech "…"` | ساخت صدای گوینده |
| `kadr gen transcribe <فایل>` | تبدیل صدا به متن با زمان هر کلمه |
| `kadr stock search "…"` / `kadr stock get 1 2` | جستجو و دانلود عکس و فیلم آزاد |
| `kadr site <آدرس>` | خوندن اطلاعات و عکس‌های یه سایت |
| `kadr silence` / `kadr scenes` / `kadr probe` | پیدا کردن سکوت‌ها، تغییر صحنه‌ها و مشخصات فایل |
| `kadr render --loudness -14` | خروجی گرفتن |
| `kadr skills --update` | به‌روز کردن skillهای یه پروژه‌ی قدیمی |

## حریم خصوصی
- ویرایشگر فقط روی `127.0.0.1` اجرا میشه و از بیرون کامپیوترت در دسترس نیست.
- فایل‌هات جایی آپلود نمیشن. فقط وقتی خودت یه سرویس رو فعال کنی (مثلاً ساخت عکس یا جستجوی عکس آزاد)، همون درخواست به همون سرویس فرستاده میشه.
- کلیدهای API فقط توی پوشه‌ی تنظیمات کاربر خودت ذخیره میشن و با دسترسی‌ای که فقط کاربر خودت می‌تونه بخونه.

## مشکلات رایج
- **بعضی سایت‌ها (Pexels، Pixabay و…) وصل نمیشن:** اگه شبکه‌ات این سایت‌ها رو مسدود کرده، از Wikimedia یا Openverse استفاده کن، یا کادر رو با VPN اجرا کن.
- **ایجنت توی لیست «نصب نشده» هست:** ابزار خط فرمانش رو نصب کن و یه بار توی ترمینال واردش شو، بعد پنجره‌ی تنظیمات رو دوباره باز کن.
- **بعد از Connect، ایجنت کادر رو نمی‌شناسه:** اون برنامه رو یه بار ببند و دوباره باز کن (یا یه گفتگوی جدید شروع کن).
