Prefer the command line?خط فرمان رو ترجیح می‌دی؟

kadr also runs as a CLI with an editor in your browser. Needs Node 22+.کادر به‌شکل یه CLI هم اجرا می‌شه و ادیتورش توی مرورگر باز می‌شه. Node نسخه‌ی ۲۲ به بالا لازمه.

git clone https://github.com/Noctis-Architect/kadr.git
cd kadr && npm link
kadr init ~/videos/launch --demo && cd ~/videos/launch
kadr serve --open

Build the desktop app yourselfساختن اپ دسکتاپ از سورس

Needs Rust, and on Linux libwebkit2gtk-4.1-dev. The installers land in src-tauri/target/release/bundle/.Rust لازمه و روی لینوکس libwebkit2gtk-4.1-dev. نصب‌کننده‌ها توی src-tauri/target/release/bundle/ ساخته می‌شن.

npm install
npm run desktop:dev     # run from source
npm run desktop:build   # make the installers
