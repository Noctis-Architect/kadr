A real editor, wired for agents. یه ادیتور واقعی، سیم‌کشی‌شده برای ایجنت‌ها.

01

A chat that editsچتی که ادیت می‌کنه

Type what you want. The agent works on this project, shows each step and the frames it checks, and every turn undoes with one click. It knows your playhead and selection.بنویس چی می‌خوای. ایجنت روی همین پروژه کار می‌کنه، هر قدم و فریم‌هایی که چک می‌کنه رو نشون می‌ده، و هر نوبت با یه کلیک برمی‌گرده. جای پلی‌هد و چیزی که انتخاب کردی رو می‌دونه.

For developersبرای دولوپرها

A composition is a web page. هر کامپوزیشن یه صفحه‌ی وبه.

Motion graphics are HTML, CSS and JS. kadr's runtime owns the clock, so CSS animations, canvas and GSAP become deterministic: the preview and the export match frame for frame. Scrub it. Change the props. موشن‌گرافیک‌ها HTML و CSS و JS هستن. ران‌تایم کادر ساعت رو در دست داره، پس انیمیشن‌های CSS، canvas و GSAP قطعی می‌شن: پیش‌نمایش و خروجی فریم‌به‌فریم یکی‌ان. اسکراب کن. پراپ‌ها رو عوض کن.
