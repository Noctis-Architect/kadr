TUTORIAL 01آموزش 01

From zero to first export.از صفر تا اولین خروجی.

Install kadr, make a project, import some footage, cut it and export it. About five minutes.کادر رو نصب کن، یه پروژه بساز، فیلم وارد کن، برش بزن و خروجی بگیر. حدود پنج دقیقه.

Installنصب

Get the installer for your system from the download page. kadr needs two things next to it:نصب‌کننده‌ی سیستمت رو از صفحه‌ی دانلود بگیر. کادر کنار خودش دو چیز لازم داره:

NeedsنیازWhyبرای چی
ffmpeg · ffprobeImport, thumbnails, waveforms and the final encode.ایمپورت، تامبنیل، شکل موج و انکود نهایی.
Chrome · Chromium · EdgeRenders HTML compositions (headless, only while exporting).رندر کامپوزیشن‌های HTML (بدون پنجره، فقط موقع خروجی).
Node 22+Only for the command-line version. The desktop app brings its own.فقط برای نسخه‌ی خط فرمان. اپ دسکتاپ خودش داره.

Chrome in an unusual place? Point kadr at it with KADR_CHROME=/path/to/chrome.Chrome جای غیرمعمولی نصبه؟ با KADR_CHROME=/path/to/chrome مسیرش رو بده.

Your first projectاولین پروژه

The desktop app opens the last project you used. The very first time it makes one for you in ~/Documents/kadr/My first video. Open or create others from the project name in the top bar, or Ctrl+O.اپ دسکتاپ آخرین پروژه‌ای که باز کرده بودی رو باز می‌کنه. بار اول خودش یکی توی ~/Documents/kadr/My first video می‌سازه. پروژه‌های دیگه رو از اسم پروژه توی نوار بالا یا با Ctrl+O باز کن یا بساز.

From the command line it is three commands. Click them:از خط فرمان هم سه تا دستوره. روشون کلیک کن:

A quick tourیه دور سریع

  • Media on the left: your footage, audio, compositions and the template gallery.Media سمت چپ: فیلم‌ها، صداها، کامپوزیشن‌ها و گالری تمپلیت‌ها.
  • Preview in the middle: drag to move a clip, right-drag to scale, the handle rotates.پیش‌نمایش وسط: بکش تا کلیپ جابه‌جا شه، با کلیک راست بکش تا اندازه‌اش عوض شه، دستگیره هم می‌چرخونه.
  • Properties and Chat on the right: everything about the selected clip, and the agent.Properties و Chat سمت راست: همه‌چیز درباره‌ی کلیپ انتخاب‌شده، و ایجنت.
  • Timeline at the bottom: tracks, the playhead, markers, in and out.تایم‌لاین پایین: ترک‌ها، پلی‌هد، مارکرها، In و Out.
  • The Workspace button switches layouts, and you can save your own.دکمه‌ی Workspace چیدمان صفحه رو عوض می‌کنه و می‌تونی چیدمان خودت رو ذخیره کنی.

Import mediaوارد کردن فایل

Drop files anywhere on the window, or Ctrl+I. They are copied into the project's media/ folder, so the project stays self-contained.فایل‌ها رو هر جای پنجره بنداز یا Ctrl+I رو بزن. توی پوشه‌ی media/ پروژه کپی می‌شن تا پروژه مستقل بمونه.

Cut and exportبرش و خروجی

Drag a clip onto the timelineیه کلیپ رو بکش روی تایم‌لاین

Press S to split at the playhead, Del to remove a pieceS برای برش در جای پلی‌هد، Del برای حذف یه تیکه

Ctrl+E, pick a preset, ExportCtrl+E، یه پریست انتخاب کن، Export

The file lands in renders/.فایل توی renders/ ساخته می‌شه.

What is in the folderتوی پوشه چیه

launch/
├─ project.json     the timeline, one clip per line
├─ comps/*.html     your compositions (motion graphics)
├─ media/           footage, audio, images
├─ renders/         exports
├─ AGENTS.md        how agents should work here
└─ .kadr/           state.json, logs, caches
