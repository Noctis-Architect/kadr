A composition is a web page.هر کامپوزیشن یه صفحه‌ی وبه.

Titles, captions, charts and transitions are HTML, CSS and JS. kadr owns the clock, so every frame renders the same in the preview and in the export.تایتل، زیرنویس، نمودار و ترنزیشن همه HTML و CSS و JS هستن. ساعت دست کادره، پس هر فریم توی پیش‌نمایش و خروجی یکسان رندر می‌شه.

Try itامتحانش کن

Scrub the time, change the props: this is what kadr does to every composition, frame by frame.زمان رو اسکراب کن و پراپ‌ها رو عوض کن: کادر دقیقاً همین کار رو فریم‌به‌فریم با هر کامپوزیشن می‌کنه.

comps/title.htmlproject.json

Anatomyساختار

<h1 data-prop="title">Hello</h1>   <!-- gets the prop's text -->

Props become controls in the inspector, so one composition serves many clips.پراپ‌ها توی پنل Properties کنترل می‌شن، پس یه کامپوزیشن به درد کلی کلیپ می‌خوره.

The clockساعت

Time only moves when kadr seeks. CSS animations, transitions and Web Animations are paused and set to t. For JavaScript:زمان فقط وقتی جلو می‌ره که کادر seek کنه. انیمیشن‌ها و ترنزیشن‌های CSS و Web Animations متوقف و روی t تنظیم می‌شن. برای جاوااسکریپت:

APIWhat it doesکارش
kadr.onFrame(fn)Runs fn(t) on every framefn(t) رو روی هر فریم اجرا می‌کنه
kadr.prop(name, fallback)Reads a propیه پراپ رو می‌خونه
kadr.time · kadr.progressSeconds, and 0–1 when a duration is setثانیه، و ۰ تا ۱ وقتی مدت تعیین شده
--t · --pThe same two, as CSS variables on :rootهمین دو تا، به‌شکل متغیر CSS روی :root
kadr.interp(t, range, values, ease)Map time to values; kadr.ease.outCubic and friendsنگاشت زمان به مقدار؛ با kadr.ease.outCubic و بقیه
kadr.random(seed)Seeded random, the same on every renderعدد تصادفی با seed، در هر رندر یکسان
kadr.delayRender()Hold the frame until fonts or images loadفریم رو نگه می‌داره تا فونت یا عکس لود شه

Look at it, lint itنگاهش کن، چکش کن

kadr comp comps/title.html 0.5 1 2      # render it alone at these times
kadr sheet comps/title.html             # contact sheet with timestamps
kadr lint                               # things that would break the export

kadr lint catches code that would make the export differ from the preview (real timers, unseeded random, …), each with a stable code and one fix.kadr lint کدهایی رو پیدا می‌کنه که باعث می‌شن خروجی با پیش‌نمایش فرق کنه (تایمر واقعی، random بدون seed و …)، هر کدوم با یه کد ثابت و یه راه‌حل.

Built-in templatesتمپلیت‌های آماده

Available to every project as @kadr/…: title, lower-third, captions, lyrics, kinetic, counter, bars, quote, logo-reveal, countdown, callout, subscribe, end-card, color, text, and the wipe, flash, iris and stripes transitions. kadr templates lists them with their props.برای همه‌ی پروژه‌ها با @kadr/… در دسترسن: title، lower-third، captions، lyrics، kinetic، counter، bars، quote، logo-reveal، countdown، callout، subscribe، end-card، color، text و ترنزیشن‌های wipe، flash، iris و stripes. kadr templates همه رو با پراپ‌هاشون نشون می‌ده.
