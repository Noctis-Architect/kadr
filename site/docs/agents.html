TUTORIAL 03آموزش 03

Use kadr from your agent.کادر رو از ایجنت خودت صدا بزن.

kadr is also an MCP server. Connect it once, then ask Claude Code, Codex or Gemini for a video in their own chat. The editor does not even need to be open.کادر یه سرور MCP هم هست. یه بار وصلش کن، بعد از توی چت خود Claude Code، Codex یا Gemini ویدیو بخواه. لازم نیست ادیتور باز باشه.

Connectوصل کردن

In the editor: AI settings → Use from your agents → Connect. Or from a terminal, one command per app:توی ادیتور: AI settings ← Use from your agents ← Connect. یا از ترمینال، برای هر برنامه یه دستور:

kadr connect claude
kadr connect codex
kadr connect gemini
kadr connect cursor
kadr connect opencode
kadr connect qwen
kadr connect claudeDesktop

Run kadr connect with no app to see what is connected.kadr connect رو بدون اسم برنامه بزن تا ببینی چی وصله.

Then just askبعد فقط بخواه

make a 30 second vertical video introducing my cafe, in ~/Videos/cafe

The agent creates the project, edits it, looks at frames to check them and exports, using kadr's tools.ایجنت با ابزارهای کادر پروژه رو می‌سازه، ادیتش می‌کنه، فریم‌ها رو برای چک کردن نگاه می‌کنه و خروجی می‌گیره.

Backups and removing itنسخه‌ی پشتیبان و حذف

Before changing an app's settings kadr makes a backup of that file. Disconnect removes only kadr's entry.قبل از تغییر تنظیمات هر برنامه، کادر از اون فایل نسخه‌ی پشتیبان می‌گیره. Disconnect فقط بخش مربوط به کادر رو پاک می‌کنه.

kadr connect claude --remove

Other MCP apps can start the server themselves: the command is kadr mcp (stdio).برنامه‌های MCP دیگه خودشون می‌تونن سرور رو اجرا کنن: دستورش kadr mcp هست (stdio).

Or work in a terminalیا توی ترمینال کار کن

Start any agent in the project folder (claude, codex, aider, …). Every project has an AGENTS.md (plus CLAUDE.md and GEMINI.md) that explains the files and the commands, and .kadr/state.json tells it what you have selected in the editor.هر ایجنتی رو توی پوشه‌ی پروژه اجرا کن (claude، codex، aider، …). هر پروژه یه AGENTS.md (به‌علاوه‌ی CLAUDE.md و GEMINI.md) داره که فایل‌ها و دستورها رو توضیح می‌ده، و .kadr/state.json بهش می‌گه توی ادیتور چی انتخاب کردی.
