TUTORIAL 02آموزش 02

Edit by talking.ادیت با حرف زدن.

The Chat tab runs an agent inside your project. It edits the same files you see, and the preview updates as it saves.تب Chat یه ایجنت رو داخل پروژه‌ات اجرا می‌کنه. همون فایل‌هایی که می‌بینی رو ادیت می‌کنه و پیش‌نمایش با هر ذخیره به‌روز می‌شه.

Pick an agentانتخاب ایجنت

Open Chat → settings. Two kinds:Chat ← settings رو باز کن. دو نوع داری:

  • An agent you already use, with its own login: Claude Code, Codex, Gemini CLI or OpenCode. No API key needed.ایجنتی که الان داری، با لاگین خودش: Claude Code، Codex، Gemini CLI یا OpenCode. کلید API لازم نیست.
  • kadr's built-in agent with your API key: Anthropic, OpenAI, OpenRouter, Gemini, DeepSeek, Z.ai, Kimi, Qwen, Mistral, Grok, Groq, Ollama (local and free) or any OpenAI-compatible server.ایجنت داخلی کادر با کلید API خودت: Anthropic، OpenAI، OpenRouter، Gemini، DeepSeek، Z.ai، Kimi، Qwen، Mistral، Grok، Groq، Ollama (محلی و رایگان) یا هر سرور سازگار با OpenAI.

Like Claude Code's tools but want a cheaper model? kadr can run Claude Code with a model from Z.ai (GLM), DeepSeek or Kimi.ابزارهای Claude Code رو دوست داری ولی مدل ارزون‌تر می‌خوای؟ کادر می‌تونه Claude Code رو با مدل Z.ai (GLM)، DeepSeek یا Kimi اجرا کنه.

Ask for editsدرخواست ادیت

Write the way you would to an editor sitting next to you. It knows where the playhead is and what is selected, so “this clip” and “here” work.همون‌طور بنویس که به یه تدوینگر کنار دستت می‌گی. جای پلی‌هد و چیزی که انتخاب کردی رو می‌دونه، پس «این کلیپ» و «اینجا» کار می‌کنه.

cut the silences out of media/talk.mp4
add a lower third for the selected clip: Sara Ahmadi, product designer
make the title animate in like a typewriter
make a 9:16 version for Reels with word-by-word captions
سکوت‌های media/talk.mp4 رو حذف کن
برای کلیپ انتخاب‌شده یه لوورترد بذار: سارا احمدی، طراح محصول
تایتل رو مثل ماشین تحریر بیار
یه نسخه‌ی ۹:۱۶ برای ریلز با زیرنویس کلمه‌به‌کلمه بساز

Watch it workکار کردنش رو ببین

Each step shows up as it happens: the files it reads, the kadr commands it runs, and the frames it renders to check its own work. You can keep editing by hand while it works.هر قدم همون لحظه نشون داده می‌شه: فایل‌هایی که می‌خونه، دستورهای کادر که اجرا می‌کنه و فریم‌هایی که رندر می‌کنه تا کار خودش رو چک کنه. وسط کارش می‌تونی دستی هم ادیت کنی.

Undo a whole turnبرگردوندن یه نوبت کامل

Before every turn kadr saves a checkpoint of project.json and comps/. One click on a turn puts everything back the way it was. Undoing an earlier turn also undoes the ones after it, and kadr asks first.قبل از هر نوبت، کادر یه نسخه از project.json و comps/ نگه می‌داره. یه کلیک روی اون نوبت همه‌چیز رو برمی‌گردونه. برگردوندن یه نوبت قدیمی‌تر نوبت‌های بعدش رو هم برمی‌گردونه و کادر قبلش ازت می‌پرسه.

Attach filesپیوست فایل

Drag or paste images, music or text into the chat box. They go into the project and the agent gets their paths.عکس، موزیک یا متن رو روی جعبه‌ی چت بکش یا Paste کن. وارد پروژه می‌شن و ایجنت مسیرشون رو می‌گیره.

Permissionsدسترسی‌ها

By default the agent works inside the project. Full access lets it run any command on your computer without asking, so kadr asks you before turning it on.به‌طور پیش‌فرض ایجنت داخل پروژه کار می‌کنه. Full access اجازه می‌ده هر دستوری رو روی کامپیوترت بدون پرسیدن اجرا کنه، برای همین کادر قبل از روشن کردنش ازت می‌پرسه.

Editing skillsمهارت‌های ادیت

Every project comes with guides the agent follows for common jobs: YouTube, Shorts/Reels/TikTok, Instagram, captions, long-to-short clips, thumbnails, voice-over explainers, podcasts, lyric videos and more. They live in .claude/skills/.هر پروژه با راهنماهایی میاد که ایجنت برای کارهای رایج دنبال می‌کنه: یوتیوب، شورتس/ریلز/تیک‌تاک، اینستاگرام، زیرنویس، کلیپ کوتاه از ویدیوی بلند، تامبنیل، ویدیوی توضیحی با گوینده، پادکست، ویدیوی متن آهنگ و بیشتر. توی .claude/skills/ هستن.

kadr skills --update    # refresh them in this project
